3. E-Commerce Product & Customer Sentiment Intelligence (Retail / Supply Chain)
Structured Data (SQL):
Orders table, inventory stock, return rates, delivery transit times, revenue by SKU.
SQL Query: "Which 3 products had the highest return rate in Q3?"
Unstructured Text (RAG):
Customer product reviews, return reason descriptions, customer support chat logs, warranty manuals.
RAG Query: "Why are customers returning that jacket? What specific complaints exist about the zipper?"
Hybrid / Agent Query:
"Find products with over 20% return rates and summarize the top 3 recurring customer defect complaints."
